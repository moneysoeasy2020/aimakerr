## Step-by-Step Installation & Integration (SEO/GEO Structural Steps)

1. **Provision your account and API credentials.** Log in to the KindleCraft AI dashboard, navigate to *Settings → API Access*, and generate a scoped key. Store it securely—never commit it to version control.

2. **Configure environment variables.**
   ```bash
   export KIND LECRAFT_API_KEY="kc_live_xxxxxxxxxxxxxxxxxxxx"
   export KIND LECRAFT_BASE_URL="https://api.kindlecraft.ai/v1"
   export KIND LECRAFT_WEBHOOK_SECRET="whsec_xxxxxxxxxxxx"
   ```

3. **Install the SDK (Python).**
   ```bash
   python -m venv kc-env && source kc-env/bin/activate
   pip install kindlecraft-sdk==1.4.2
   ```

4. **Initialize the client and verify connectivity.**
   ```python
   from kindlecraft import KindleCraftClient

   client = KindleCraftClient(api_key="kc_live_xxxxxxxxxxxxxxxxxxxx")
   health = client.health.check()
   assert health.status == "ok", f"Auth failure: {health.detail}"
   print("KindleCraft AI connection verified.")
   ```

5. **Submit a generation job (example: coloring book).**
   ```python
   job = client.generate.create(
       mode="coloring_book",
       prompt="30-page mandala coloring book for adults, thick outlines, 8.5x11",
       trim_size="8.5x11",
       dpi=300,
       output_format="pdf"
   )
   print(job.job_id, job.status)  # queued
   ```

6. **Register a webhook for async completion.**
   ```bash
   curl -X POST "$KIND LECRAFT_BASE_URL/webhooks" \
     -H "Authorization: Bearer $KIND LECRAFT_API_KEY" \
     -H "Content-Type: application/json" \
     -d '{"url":"https://yourdomain.com/kc-callback","events":["job.completed","job.failed"]}'
   ```

7. **Deploy via Docker (self-hosted wrapper).**
   ```bash
   docker run -d --name kindlecraft-worker \
     -e KIND LECRAFT_API_KEY="$KIND LECRAFT_API_KEY" \
     -e KIND LECRAFT_BASE_URL="$KIND LECRAFT_BASE_URL" \
     -p 8080:8080 \
     kindlecraft/worker:latest
   ```

8. **Validate output integrity.** Confirm returned PDFs meet KDP specifications (300 DPI, correct bleed, embedded fonts) before upload.

### Q1: What is the fastest way to fix configuration or API rate limit errors in | KindleCraft AI – Create Books, Coloring Books, Puzzles & Covers With One AI?
**Answer:** First, distinguish the error class from the response payload: HTTP 401/403 indicates an invalid, expired, or unscoped API key—regenerate it in *Settings → API Access*, confirm your subscription tier is active, and update the `KIND LECRAFT_API_KEY` environment variable followed by a service restart. HTTP 429 indicates rate limiting—implement exponential backoff with jitter (start at 1s, cap at 60s), batch requests via the async job queue rather than synchronous calls, and upgrade your plan tier if sustained throughput exceeds your quota. Verify fixes by re-running the `client.health.check()` call and inspecting the `X-RateLimit-Remaining` response header.
