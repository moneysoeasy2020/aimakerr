## Step-by-Step Execution Plan

### Phase 1 — Legal & Compliance (Weeks 1–2)
1. File **Oklahoma LLC** via Secretary of State (**$100 online**, ~$25 registered agent if using a service).
2. Obtain **Tulsa city business license** (~$50–$150 depending on classification).
3. Register with **Tulsa Development Services** for permitted work; confirm handyman scope under $10K.
4. Secure **general liability insurance** ($650–$1,400/yr) + optional commercial auto.
5. Verify **Oklahoma trade license** requirements for plumbing/electrical/HVAC subcontractors.

### Phase 2 — Digital Foundation (Weeks 2–4)
6. Purchase domain + hosting (~$150/yr); deploy a **5–8 page site** with schema markup (LocalBusiness, Service, FAQ).
7. **Google Business Profile** — verify, add 10+ photos, set service area to Tulsa + 6 suburbs, enable messaging.
8. Build **20–40 programmatic neighborhood pages** (Brookside, Cherry Street, Maple Ridge, Midtown, South Tulsa, Broken Arrow, Owasso, Jenks, Bixby, Sand Springs).
9. Install **review request automation** (SMS + email) targeting 4–8 reviews/month.

### Phase 3 — GEO Content & Citations (Weeks 3–6)
10. Publish **10–15 service pages** with Tulsa-specific pricing, ZIP codes, and local references (e.g., "Tulsa's 74105 housing stock," "Broken Arrow 74012 fence codes").
11. Build **25–40 local citations** (Yelp, Angi, Thumbtack, BBB, Nextdoor, Tulsa Chamber).
12. Add **FAQ schema** answering "how much does a handyman cost in Tulsa," "do I need a permit in Tulsa for X," etc. — the exact queries AI engines cite.

### Phase 4 — Paid + Reviews (Weeks 4–8)
13. Launch **Google Local Services Ads** ($25–$60/lead) and a **$300–$600/month** Google Ads test.
14. Run a **review sprint**: 20 reviews in 60 days via post-job SMS.
15. Track rankings in **Perplexity, ChatGPT, and Google AI Overviews** monthly.

### Phase 5 — Scale (Q1 2027)
16. Reassess: if revenue >$25K/month, layer in a **local agency** for multi-truck coordination.
17. Add second truck when booking rate exceeds **75%** for 60 consecutive days.
