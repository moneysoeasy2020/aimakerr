## Step-by-Step Execution Plan

### Phase 1 — Foundation (Weeks 1–3)
1. **Entity & licensing:** File AZ LLC ($50), obtain Phoenix Transaction Privilege Tax license (free), register with AZ Registrar of Contractors if offering water-damage restoration.
2. **Insurance:** General liability + commercial auto — budget **$180–$320/mo**.
3. **Equipment:** Used truck-mount ($9,000–$16,000) + portable backup ($1,800–$3,200) + chemicals/spotting kit ($600–$900).
4. **Brand + domain:** Secure `.com` with "carpet cleaning phoenix" semantic variant; set up Google Business Profile same week.

### Phase 2 — Digital Asset Build (Weeks 3–8)
5. Launch 5-page site with **LocalBusiness + Service schema**, service-area pages for **12 core Phoenix ZIPs** (85032, 85050, 85254, 85251, 85018, 85258, 85308, 85085, 85226, 85283, 85044, 85202).
6. Deploy programmatic pages: *"[Neighborhood] carpet cleaning"* — target **30–50 pages** covering Ahwatukee, Arcadia, Desert Ridge, Scottsdale border zones.
7. Set up call tracking + booking widget; wire review-request automation.

### Phase 3 — Demand Capture (Weeks 6–16)
8. Launch Google Ads: **$1,200–$1,800/mo** on "carpet cleaning near me," "pet stain removal [city]," "tile cleaning Phoenix" — target **$35–$55 cost per booked job**.
9. Activate B2B channel: pitch **40–60 property managers** in apartment-heavy ZIPs (85032, 85202) for recurring turnover cleans at **$0.16–$0.20/sq ft**.
10. Snowbird campaign (Oct–Nov): "pre-arrival deep clean" package at **$289–$419** for 1,800–2,400 sq ft homes.

### Phase 4 — Scale & Defend (Weeks 16–26)

12. Add second van once monthly booked jobs exceed **85–95** (break-even utilization).
13. Reinvest **8–12% of revenue** into local SEO and programmatic page expansion — target **$9K–$14K/mo revenue by month 6**.
